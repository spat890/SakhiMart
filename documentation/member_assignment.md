# Member-wise handoff

Each member owns the files listed below. Work in the same Git repository and do not create a separate project folder/repository unless the team lead asks.

| Member | Owned files | Required proof |
|---|---|---|
| 1 Cybersecurity | `security/authentication_demo.py`, `security/ledger.py` | Terminal screenshot of both scripts |
| 2 Core CS | `app.py`, `backend/`, `templates/`, `static/` | Browser screenshots of registration, product and savings |
| 3 AI Product Intelligence | `ai/product_intelligence/` | Image checker and pricing screenshots |
| 4 Hindi Voice Assistant | `ai/voice_assistant/index.html` | Browser screenshot showing recognized/manual command |
| 5 Business Advisor | `ai/business_advisor/`, `data/sales.csv` | Pandas output screenshot |
| 6 Monitoring & Feedback | `ai/feedback_monitor/` | Alert output screenshot |

Every member must:
1. Run their module.
2. Capture genuine input/output screenshots.
3. Report errors and fixes.
4. Add a short explanation of the code and its limitations.
5. Commit only their assigned files unless coordinated with the team lead.
